# Blender-BatchUV-MaterialSync
Blender add‑on, batch UV unwrap in Object Mode, sync multi‑material across linked objects by face‑UV matching.
# 批量UV展开与材质关联 · 使用说明

一个 Blender 插件: 在物体模式下对选中的全部网格物体批量执行自动 UV 展开, 并按 UV
展开图把"源物体上分了不同区域的材质"完整关联到其它物体; 能检测镜像修改器与已经应用
过的镜像, 并自动把镜像物体的 UV 对齐成与源一致。

插件版本: 1.1.0
面板位置: 3D 视图 侧边栏 (按 `N`) 的 **UV工具** 分类

最常见的问题:

1. 按 UV 关联材质的前提是两个物体的 UV 展开图一致。面板上的"逐个物体处理"必须
   保持勾选; 取消勾选后所有物体共用一张 UV 布局, 各物体之间的 UV 并不相同, 之后按
   UV 匹配会失败(插件会在匹配率过低时弹出提示)。
2. 插件会直接改写材质槽和 UV。*关联材质时目标的 UV 可能被镜像/对齐, 所以对重要
   文件先存盘; 操作都在撤销栈里, 出错可以按 `Ctrl+Z` 整体撤回。
3. 摄像机、灯光、空物体等非网格物体会被自动跳过

 安装

Blender 4.2 及以上:

```
编辑 > 偏好设置 > 扩展 > 右上角下拉菜单 > 从磁盘安装 > 选择 batch_uv_material_linker-1.1.0.zip
```

安装后启用插件, 3D 视图按 `N`, 侧边栏出现 "UV工具"分类, 里面是 "批量UV展开 / 材质关联"
面板。

最常用的三步:

1. 物体模式下选中要处理的全部网格物体, 点"批量展开选中物体"。
2. 把已经分好材质的那个物体设为活动物体(最后点选它), 其余要保持一致的物体一起选中。
3. 点 "关联材质到选中物体"。


面板底部会列出每个物体的处理结果

面板参数详解

自动UV展开

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 展开方式 | 智能UV投影 | 四种: 智能UV投影 / 展开(角度、共形、最小拉伸) / 光照图打包 / 立方体投影 |
| 角度限制 | 66° | 仅智能投影。判断面是否属于同一个 UV 岛的角度阈值, 调小切得更碎、调大更整 |
| 岛间距 | 0.001 | 仅智能投影。UV 岛之间的间隔 |
| 面积权重 | 0.0 | 仅智能投影。0 表示不按面积调整密度 |
| 间距方式 | 按比例缩放 | 仅智能投影。可选 按比例缩放 / 直接相加 / 按比例(%) |
| 旋转方式 | 轴向对齐(自动) | 仅智能投影。轴向对齐(自动/垂直/水平)、90°对齐; 当前版本不支持的值会自动换成最接近的 |
| 展开算法 | 角度法 | 仅"展开"方式。角度法 / 共形 / 最小拉伸 |
| 边距 | 0.001 | 仅"展开"方式 |
| 平均岛缩放并重新打包 | 开 | 仅"展开"方式。展开后统一 UV 密度再打包 |
| 投影大小 | 1.0 | 仅立方体投影 |
| 光照图边距 | 0.1 | 仅光照图打包 |
| 修正纵横比 | 开 | 按图片/物体比例修正 |
| 适配边界 | 关 | 把 UV 缩放到 0-1 范围内 |
| 逐个物体处理 | 开 | 保持开启。每个物体单独展开, 相同形状的物体会得到完全一样的 UV 展开图 |

关联材质分布

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 匹配依据 | UV展开图一致 | UV展开图一致 / 面序号一致 / 3D位置一致 |
| UV容差 | 0.001 | 仅 UV 匹配。UV 空间中认定两个面重合的距离阈值, 对不上时可适当调大 |
| 位置容差 | 0.001 | 仅 3D 位置匹配。场景单位下的距离阈值 |
| 未匹配的面 | 保留原有材质 | 取最近的源面 / 用源物体第一个材质 |
| 同时复制源物体的UV布局 | 关 | 拓扑一致时直接把源的 UV 复制给目标, 之后逐面一一对应 |
| 多用户网格自动转单用户 | 开 | 目标网格被多个物体共用时先复制一份, 避免误改其它物体 |

三种匹配依据怎么选:

| 匹配依据 | 适用场景 | 前提 |
| --- | --- | --- |
| UV展开图一致 | 默认; 两个物体各自展开后 UV 布局一致 | 两边有 UV 且布局一致 |
| 面序号一致 | 两个物体是同一份网格的副本 | 拓扑完全一致 |
| 3D位置一致 | 叠在同一个位置的副本、镜像件 | 形状相同, 位置对得上 |

镜像处理

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 检测镜像(修改器/已应用的镜像) | 开 | 检测 Mirror 修改器; 修改器已应用时用几何对称检测 |
| 镜像物体自动对齐UV | 开 | 目标与源成镜像关系时, 自动把 UV 对齐成与源一致 |
| 镜像轴 | 自动检测 | 也可以手动指定 X / Y / Z |
| UV镜像方向 | 自动 | 自动挑匹配率最高的方案; 也可以限定只镜像 U、只镜像 V 或 U+V |
| 镜像检测容差 | 0.0005 | 相对物体尺寸的比例, 越大越容易判为镜像 |

镜像检测的两条途径:

有 Mirror 修改器: 直接读出镜像轴, 以及修改器自身的 UV 镜像开关(U/V)。
修改器已经应用**(网格里只剩对称两半): 用几何对称检测(顶点镜像配对率)照样查得出来,
  实测相似度 100%。所以"应用后才能不能查出来"这件事是成立的。

判定为镜像后, 自动对齐 UV 的做法是: 先按镜像对应关系把源的 UV 逐面复制过来(按顶点
序号对应), 再依次尝试 U 镜像、V 镜像、U+V 镜像, 取 UV 匹配率最高的方案; 如果原来的
UV 本来就最好, 就一个字都不改, 只在结果里写"未改动"。
顶部与结果区

选中网格物体: 当前选中的网格数量
源物体: 关联材质时的源(也就是活动物体)
结果列表: 每个物体的处理结果, 前面带图标(对勾 = 全部匹配, 感叹号 = 部分未匹配, 叉 = 匹配率过低或失败)

按钮一览

| 按钮 | 算子 | 作用 |
| --- | --- | --- |
| 批量展开选中物体 | `uvmb.unwrap_selected` | 对选中网格批量展开, 自动跳过非网格物体 |
| 关联材质到选中物体 | `uvmb.link_materials` | 以活动物体为源, 关联材质分布 |
| 检查UV匹配度 | `uvmb.check_match` | 只检查不修改, 报告每个物体的匹配面数 |
| 检测镜像 | `uvmb.detect_mirror` | 只检查不修改, 报告每个物体的镜像情况 |
| 展开 + 关联材质 (一键) | `uvmb.unwrap_and_link` | 先全部展开, 再以活动物体为源关联材质 |
典型工作流

一批相同形状的物体, 共用同一套材质分区

比如十个同款零件, 先在其中一个上分好区域给材质, 其余的要一模一样。

1. 全选这十个物体, 确认"逐个物体处理"是开着的, 点 **批量展开选中物体**。
   逐个展开能保证相同形状的物体拿到完全一样的 UV 展开图(实测逐面 UV 值完全一致)。
2. 把分好材质的那个设为活动物体, 其余九个一起选中。
3. 点 **关联材质到选中物体**。结果列表应当全部是 `100%`; 有任何"未匹配"就先点
   **检查UV匹配度** 看是哪一步出了问题。

左右镜像的两个部件

比如左臂 / 右臂这种互相镜像的物体, 材质只需要在一侧画。

1. 两个物体一起选中并展开(逐个物体处理保持开启)。
2. 在源物体(比如左臂)上分区域给材质, 把它设为活动物体, 选中右臂。
3. 点 **关联材质到选中物体**。插件会先判定两者是镜像关系, 再自动把右臂的 UV
   对齐成与左臂一致, 最后按 UV 把材质分布搬过去。

结果列表里会写明用了哪种对齐方式
如果不想让插件动 UV, 把"镜像物体自动对齐UV"取消勾选, 它就只显示镜像关系。

网格已经应用过镜像修改器

1. 选中物体点"检测镜像", 结果里会写"网格关于X轴对称(相似度 100%, 常见于已应用的镜像修改器)"。
2. 这种物体照常参与批量展开与材质关联, 不需要特殊处理。
3. 如果这个物体自己有"一半画了材质、另一半没画"的情况, 见下面"限制"一节。

只检查不修改

在正式操作前想确认能不能成功:

1. 选中源物体(活动)和目标物体, 点"检查UV匹配度"。
2. 结果列表给出每个物体的匹配面数和百分比; 源物体与目标成镜像关系时也会一并说明。
3. 点"测镜像"单独查看镜像情况。

两个检查算子都不修改任何数据。

从脚本调用

算子 id 都以 `uvmb.` 开头, 设置存在 `scene.uvmb_settings` 上:

```python
import bpy

settings = bpy.context.scene.uvmb_settings
settings.method = 'SMART'        # 展开方式
settings.per_object = True       # 逐个物体处理(按 UV 关联材质时必须开)
settings.match_mode = 'UV'       # 匹配依据
settings.mirror_uv_fix = True    # 镜像物体自动对齐 UV

bpy.ops.uvmb.unwrap_selected()   # 批量展开
bpy.ops.uvmb.check_match()       # 检查匹配度(不改数据)
bpy.ops.uvmb.link_materials()    # 以活动物体为源关联材质
```

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点按钮没反应 / 按钮是灰的 | 不在物体模式, 或没选中网格物体 | 切到物体模式; "关联材质"还需要源之外至少一个网格 |
| 报错"源物体没有 UV 图层" | 源物体还没展开 | 先跑一次 **批量展开选中物体** |
| 结果里大量"未匹配 N 个面" | 两边 UV 展开图不一致 | 确认"逐个物体处理"是开着的; 或改用"同时复制源物体的UV布局"; 或点 **检查UV匹配度** |
| 提示"只有 x% 的面在源物体上找到对应的面" | 匹配率低于 50%, 插件给的是提醒不是错误 | 按提示排查; 确实对得上时可以把 UV容差 调大一点 |
| 目标的材质槽变多了 | 目标原有材质会保留, 源的材质追加在后面 | 想让目标只用源的材质, 手动清掉它原来的槽位 |
| 关联后目标的 UV 变了 | 触发了"镜像物体自动对齐UV" | 不需要就取消勾选这一项 |
| 改了一个材质, 好几个物体一起变 | 关联的是同一个材质数据块, 这是刻意行为 | 需要独立材质就先复制材质再关联 |
| 摄像机/灯光被选中了 | 插件自动跳过, 不报错 | 结果列表里会写"已跳过 · 相机不是网格物体" |
| 物体是曲线/文字, 没被展开 | 插件只处理网格物体 | 先 `物体 > 转换 > 网格` |
| 物体很多时展开偏慢 | "逐个物体处理"每个物体都要进出一次编辑模式 | 物体极多且不需要按 UV 关联材质时, 可以关掉它一次性展开 |

行为细节

选择状态会还原: 批量展开会临时改选择/活动物体, 结束后自动恢复成原来的样子。
可以撤销: 三个会改数据的入口(批量展开、关联材质、一键)都注册在撤销栈里, `Ctrl+Z` 整体撤回。
匹配方式: 以每个面在 UV 空间中的中心点建哈希索引, 容差内择优, 并用 UV 面积做次要判据。
低匹配率只提醒不阻断: 匹配率低于 50% 时给出排查提示, 仍然完成操作。
材质共享: 关联过去的是同一个材质数据块, 不是副本; 改一个材质所有使用它的物体都会变。
材质槽追加: 目标的槽位保留, 源的槽位按需追加, 逐面写入 `material_index`。
多用户网格: 目标网格被多个物体共用时会先复制成独立网格, 避免误改别的物体(可关)。
非网格物体: 一律跳过, 并在结果列表里记录类型。
旋转方式在 5.x 变成了轴向对齐的水平/垂直)会自动映射成合法值。
结果列表: 每次操作会刷新面板底部的列表; 图标对勾表示全部匹配, 感叹号表示部分未匹配,
每个物体下面多出来的一行是这一物体的补充说明(镜像处理、未匹配面数、跳过原因等)。

限制
关联材质是"源物体 → 目标物体"的操作。**同一个物体内部**"只画了一半, 想把另一半也填上"
目前没有一键按钮: 用 Mirror 修改器保持非破坏状态时, 镜像出来的那一半本来就会继承材质;
如果已经应用了修改器又想补另一半, 可以复制一份物体、把它做镜像, 再让原物体当源关联过去。
只处理网格物体, 曲线/文字/元球等需要先转成网格。
如果两个物体本身都是严格对称的形状, 判定"是否互为镜像"时会以哪种方案匹配率更高为准,
不会强行改 UV。
关联的是材质数据块本身, 不涉及材质内部的贴图坐标之类的额外设置。
